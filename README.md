# SQL Practice

My personal SQL learning journey with hands-on practice queries.

## 📁 Files

| File | Description |
|------|-------------|
| `01_day1_basic_practice.sql` | CREATE TABLE, INSERT, SELECT, UPDATE (CRUD operations) |
| `02_day2_advanced_queries.sql` | GROUP BY, Aggregate functions, LIMIT, Subqueries |
| `02.1_day2_practice_Notes` | Detailed explanations of important SQL concepts |

- ORDER BY (ASC / DESC)
- Aggregate Functions (SUM, AVG)
- GROUP BY
- LIMIT
- Subqueries
- String functions (`split_part`)

1. Create the `employees` table using the Day 1 file
2. Insert the sample data
3. Run the practice queries one by one
4. Read the notes for better understanding
